local chain 31337 · no wallet needed to configure. Creating a draft does not deploy, sign, charge or move funds.

Token pair

Start with your token.

Supply values are exact base-unit integers. QLQ is a local test quote asset with 18 decimals, not a stablecoin. Initial supplies go to the connected wallet; ordinary token transfers are not quantum-protected.

Graduation

Choose when liquidity moves.

Later policy changes require your wallet and quantum key, followed by the notice period selected above. Migration stays on one EVM chain and the same fixed manager/token pair. There is no bridge.

Initial position

Set the opening liquidity.

Currency 0 and 1 follow sorted token addresses, which are resolved during setup. Check which is your token and which is QLQ before funding. Actual balances, allowances, hook identity and pool state are checked again when preparing initialization.

Take it from here.

The toolkit contains the existing compiled template, ABI and bytecode, source snapshots, client modules, notices, and your draft. This prepares an export—it does not compile new contracts or certify a new configuration. Your wallet and quantum key are created or connected separately in setup.

Import a saved configuration

A deliberate launch.

SLH-DSA-SHA2-128s protects specified controller and liquidity actions together with your wallet signature. The template has local transaction tests, not an independent audit. There is no key recovery in this version; losing either fixed key can strand protected liquidity. Source principal cannot exit before graduation. Service fees are off.
