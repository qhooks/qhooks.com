Your token.
Your next chapter.

Launching or managing a token on a supported network? Choose your chain and open the launch workspace. This separate workspace preserves projects on local chain 31337.

Set up the token pair and two-key controller behind QGraduation. Build toward a net-quote threshold, choose manual graduation, or keep your source pool in place.

Integration notes

local chain 31337 only · not independently audited. Use disposable local accounts and assets.

Connect your wallet.

No wallet is connected automatically. This setup uses the hash-based SLH-DSA-SHA2-128s profile. The separate ML-DSA-65 launch workflow remains available with its own explicit fee review.

01 / Quantum key

Keep the second key yours.

Your passphrase and secret key stay in the client. Download an encrypted backup, then select that saved file to verify it. This dedicated graduation backup is separate from QWallet and QPool backups.

No quantum key loaded.

There is no key rotation or recovery in this version. Losing either key can permanently prevent protected actions. Keep your backup and passphrase separately.

02 / Token pair

Set the starting point.

· Configure in the Lab

The initial token supplies go to your connected wallet. Ordinary token transfers are not quantum-protected. QGraduation protects specified controller and liquidity actions with both keys.

Save or import public setup progress
Public transaction progress stays in this browser. It contains configuration and public identities, never a private key, encrypted backup or passphrase. Close the current setup before importing another.

  

 

 
From setup to graduation.
After all setup deployments are confirmed, open your liquidity workspace to initialize a position, choose a graduation policy, migrate, and manage payouts. This screen handles setup only. The threshold measures net raw quote-token inflow, not market cap. Migration stays on the same EVM chain and fixed v4 manager—there is no bridge.
SLH-DSA-SHA2-128s is a category 1 signature profile; ML-DSA-65 is category 3. They are not interchangeable security levels.
