My QHooks

Builders program

Grants and bounties for hooks and modules.

QHooks funds builders who extend the ecosystem: new launch blocks, modules that pay holders, post-quantum hooks for the Lab, and the tools around them. Bring an idea for a grant, or pick up a bounty when one opens.

Submit a modulePropose something else ↗

Two ways in.

Grants

You bring the idea.

Propose a hook, module or tool. If it fits, we agree the scope, the milestones and the grant with you in writing before you start, and pay as the milestones land.

Bounties

We bring the brief.

Work we already know we want, posted here with its scope and reward. The first complete submission that passes review takes it.

No bounties are open right now. New ones are announced on @qHooks_ ↗.

What we fund.

  • Modules

    New ways for holders to earn

    Payee modules beyond staking and raffles, built on the module template. Listed modules also pay their builder up to 10% of what they receive, in every launch that uses them.

    Builder guide →
  • Launch blocks

    New rules for a launch

    Guards, fees, burns and games that run on every trade, fixed at launch and cheap enough to sit in a busy pool.

    See the 21 blocks →
  • Post-quantum hooks

    New Lab templates

    Hooks whose controls need a wallet signature and a post-quantum signature over the same action, like QGraduation and Circuit Recovery.

    Open the Lab →
  • Tools

    Integrations around QHooks

    Bots, dashboards, alerts and examples that use the public API, so creators and traders can use QHooks where they already are.

    API →
  • Reviews

    Tests and independent review

    Fuzz tests, invariant suites and written reviews of QHooks contracts and modules, published with their findings.

    Review checklist →

How it works.

  1. 01

    Tell us what you’ll build

    Modules go through the submission form. For hooks, tools and reviews, send a short proposal to @qHooks_ ↗.

  2. 02

    Review

    We read the code against the public review checklist: no owner keys, users can always withdraw, builder earnings only as the template allows.

  3. 03

    Agree the work

    Scope, milestones and the grant or bounty reward are written down before you start.

  4. 04

    Ship it

    Reviewed modules are listed in the Studio, where any creator can add them to a launch. Your builder share is set in the module’s code.
