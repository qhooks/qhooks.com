How it works.

  1. Tell us what you’ll buildModules go through the submission form. For hooks, tools and reviews, send a short proposal to @qHooks_ ↗.
  2. ReviewWe read the code against the public review checklist: no owner keys, users can always withdraw, builder earnings only as the template allows.
  3. Agree the workScope, milestones and the grant or bounty reward are written down before you start.
  4. Ship itReviewed modules are listed in the Studio, where any creator can add them to a launch. Your builder share is set in the module’s code.
