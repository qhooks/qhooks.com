Robinhood ChainQHooks Arb

Arb this gap

You keep 85% of the gap; 15% buys QHOOKS and burns it. Gaps close fast; the trade cancels itself if the gap is gone.

Refreshing routes…

How it works

  • One open contract on Robinhood Chain closes a price gap between two pools of the same token in a single transaction. You need no funds up front, only gas.
  • Routes only use plain pools (fee 3% or less) and pools whose hook is on a reviewed list held by the QHooks Safe. Each listed hook is pinned to its code, so a hook that changes drops off by itself.
  • Every route is checked before you send; if the gap is gone by the time your transaction lands, it cancels itself.

Routes
/arb-routes-rh.json: each route's pool keys and swap directions, start currency ETH or WETH
Function
recapture(((address,address,uint24,int24,address),bool)[] legs, uint256 amountIn, uint256 minGap) returns (uint256 gap, uint256 burned)
  • 2 to 4 legs, a cycle that starts and ends in ETH or WETH; every middle token must net to zero.
  • The caller receives 85% of the gap in the start currency; 15% buys QHOOKS in its own pool (price-capped) and burns it.
  • Simulate with your real fee fields. Some hooks price a call without fee fields differently from a real transaction.
  • You can build your own routes from any pools that meet the rules; the list is a starting point, refreshed with releases.
Example 
const routes = (await (await fetch('https://qhooks.com/arb-routes-rh.json')).json());
// For each route: eth_call recapture(legs, amountIn, 0) on the executor at a few sizes,
// WITH your real fee fields (maxFeePerGas / maxPriorityFeePerGas) — never a bare call.
// A result of (gap, …) means a gap is open; a revert means there isn't one at that size.
// Then send the same call with minGap = ~90% of the simulated gap, from your bot's wallet.
// Calldata: selector 0x6794ea77, then abi-encoded (legs, amountIn, minGap).
