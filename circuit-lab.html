My QHooks
QHooks Lab / Circuit Recovery

A pause with a protected restart.

Set a per-swap input threshold for each direction. A threshold-reaching trade completes, then later swaps pause. Recovery requires both wallet and post-quantum approval after your cooldown.

Integration notes

local builds only (ML-DSA key setup fits only Base and BNB Chain) · not independently audited.

Each threshold is a positive integer in that token’s smallest units—not a dollar amount. Token 0 input applies to 0 → 1 swaps; token 1 input to 1 → 0. Actual executed input includes fees. Token decimals matter. These are per-swap thresholds, not cumulative budgets.

What your build includes

Your configured controller, governed hook, manager, key registry and verifier, plus the complete 64-file Solidity source project and compiler input. Exports include helper bytecode and third-party notices.

This builder targets local chain 31337. It uses the optional ML-DSA profile, with expensive onchain key setup—not the cheaper hash-based profile. Its one-time key setup takes about 40M gas, which fits within a single transaction only on Base and BNB Chain; Ethereum, Arbitrum and Robinhood Chain cap transactions below that. Token launches use the hash-based profile and are not affected. Building here is free and does not connect a wallet, enroll keys, deploy contracts or move funds. For that reason Circuit Recovery is not offered for public-chain deployment from the Lab; Deploying to a public chain (below) instead uses the hash-based SLH-DSA key profile token launches use: about 1M gas for the shared verifier, once per chain, so it fits every supported chain.Creator Revenue and Dynamic Fees deploy to all five chains with the hash-based profile.

Integration notes

Supply verified infrastructure, ordered ERC20 addresses, a policy, wallet owner and enrolled public key at deployment. Find the hook permission salt for the actual controller address and child initcode. No test keys or private keys are included.

Either direction reaching its threshold pauses both directions after that trade completes. Partial fills use actual executed input. Liquidity operations are unaffected. This is not a stop-loss, oracle, price guarantee or protection against LP losses.

Recovery binds the exact previous trip and old/new thresholds. Generation and trip history remain recorded. The manager must be locked. Unavailable signers can leave trading paused indefinitely.

The base contracts have local integration tests. Compiling your settings does not run a new behavioral test. Connected recovery-governance and deployment are separate workflows.
